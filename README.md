# 헌터세계관 사이트

예나 · 시은 · 시현 · 연우 · 하린의 헌터 세계관 사이트예요. 서버 없이 GitHub Pages 로 돌아가요.

## 폴더 구조

```
index.html        홈
world.html        세계관
characters.html   캐릭터 목록
character.html    캐릭터 상세 (주소: character.html?id=캐릭터id)
guild.html        길드 상세 (주소: guild.html?id=길드id)
gallery.html      갤러리 (그림 + 만화 통합, 태그 검색)
comic.html        만화 뷰어 (갤러리에서 들어와요)
playground.html   놀이터 (게임/퀴즈/체크리스트 넣을 빈 페이지)
couple.html       커플 (data/couples.js 로 채워요)
add.html          그림 추가 코드 만들어주는 도우미
data/             ← 내용은 전부 여기! (site / guilds / characters / couples / gallery / comics / world / music)
theme.js          다크/라이트 모드
player.js         음악 플레이어
images/           ← 그림 파일
style.css, app.js 디자인 / 공통 기능 (보통 안 건드려도 돼요)
```

## 내용 추가하기

**그림 · 만화 추가 (버튼 하나로)** — GitHub 를 쓰는 관리자만 하면 돼요
1. 친구들이 보낸 그림 파일을 컴퓨터/폰에 모아요. (파일 이름 그대로 OK. 한글·띄어쓰기 OK)
2. `add.html` 을 열어요. (사이트 주소 뒤에 `/add.html`)
3. 처음 한 번만 위쪽 **GitHub 연결**에 토큰을 넣어요 (아래 "토큰 만드는 법")
4. 그림 파일들을 한꺼번에 고르고(여러 장 OK), 그린 사람·캐릭터·태그를 채워요. 제목은 파일 이름으로 자동이에요. 만화는 위에서 "만화"를 눌러요 (↑ ↓ 로 페이지 순서 바꾸기)
5. **GitHub 에 바로 올리기** 를 누르면 그림 파일과 목록(`data/gallery.js` 또는 `data/comics.js`)이 한 번에 저장돼요. 1~2분 뒤 사이트에 나타나요. 복사·붙여넣기는 필요 없어요.
- 올리는 도중 문제가 생기면 아무것도 올라가지 않아요 (한 번에 전부 저장하거나, 하나도 저장하지 않아요).
- 같은 이름의 파일이 이미 있으면 덮어쓸지 물어봐요.
- 연결 없이 쓰려면 아래쪽 "코드로 보기"에서 코드를 복사해서 `data/gallery.js` 맨 아래 `];` 바로 위에 붙여넣어도 돼요 (그림 파일은 따로 올려야 해요).
→ 그림에 `characters` 로 단 캐릭터 태그가 자동으로 그 캐릭터 페이지에도 나와요.

**토큰 만드는 법 (한 번만)**
1. GitHub 오른쪽 위 내 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
2. 이름은 아무거나, 만료 기간은 길게 (만료되면 새로 만들어서 다시 연결해요)
3. Repository access → **Only select repositories** → 이 사이트 저장소 하나만 선택
4. Permissions → Repository permissions → **Contents: Read and write**
5. Generate token → 나오는 글자를 복사해서 `add.html` 의 토큰 칸에 붙여넣고 "연결하기"
- 토큰은 그 기기의 브라우저에만 저장돼요 (사이트 파일이나 GitHub 에는 안 올라가요). 비밀번호처럼 남에게 보여주지 말고, 공용 컴퓨터에서는 쓴 뒤 "연결 해제"를 눌러요.
- 토큰은 이 저장소 하나에만 쓸 수 있게 만들었으니, 잃어버리면 GitHub 의 같은 화면에서 삭제(Revoke)하면 돼요.

**캐릭터 프로필 채우기**: `data/characters.js` 에서 해당 캐릭터 줄의 `summary`, `info`, `desc`, `image` 를 채워요. 프로필 그림은 `images/characters/` 에 올려요.
- `info` 가 캐릭터 상세 페이지의 **표**가 돼요: 주인 · 성별 · 나이 · 키 · 소속 · MBTI · 무기 · 포지션 · 능력 · 등급 · 눈 색 · 머리색 (주인/소속은 `owner`/`guild` 에서 자동)
- `눈 색` / `머리색` 은 `"#c8d2ff"` 또는 `"rgb(200,210,255)"` 로 쓰면 색 네모 + RGB 값이 나와요
- `desc` 는 표 **아래** 글이에요
- 표 아래 **📄 캐릭터 시트** 버튼을 누르면 팝업이 떠요. 팝업에는 캐릭터 줄의 `sheet` 칸에 직접 적은 글(챗봇용 시트)이 그대로 나오고, `시트 복사` 로 통째로 복사할 수 있어요. 비워 두면 "아직 비어 있음"으로 나와요

**관계**: 캐릭터 줄의 `relations` 칸에 써요. 캐릭터 페이지 맨 아래 "관계" 칸에 나오고, **상대는 왼쪽 · 이 캐릭터는 오른쪽** 사이에 화살표가 그려져요.
- 한 명당 한 줄: `{ who: "sieun-e", rel: "연인", dir: "<>", color: "빨강", main: true, text: "설명" }`
- `who` = 상대 캐릭터 id (누르면 그 캐릭터 페이지로 가요) 또는 그냥 이름 (같은 관계인 사람이 여러 명이면 `who: ["id1", "id2"]` 처럼 대괄호로 묶어요) / `rel` = 화살표 위 작은 글씨 / `text` = 아래 설명
- `dir` = 화살표 방향. `"<>"` 서로 (상대 ↔ 이 캐릭터) · `"<"` 이 캐릭터가 상대를 (상대 ← 이 캐릭터, 예: 일방적 혐오) · `">"` 상대가 이 캐릭터를 (상대 → 이 캐릭터). 안 쓰면 `"<>"`
- `color` = `빨강` `주황` `초록` `파랑` `검정` (또는 `#ff00aa`). 안 쓰면 회색
- `main: true` = 주요 관계 (이름·설명 굵게 + ★). 설명 안에서 일부만 굵게 하려면 `[굵게:글자]`

**커플**: `data/couples.js` 에서 `members` 에 두 캐릭터 id 를 쓰면 `couple.html` 에 나와요. `summary`(한 줄) · `info`(표: 관계/호칭/만난 계기/시작/분위기/데이트/키워드/노래) · `desc`(글). 갤러리에서 두 캐릭터를 같이 태그한 그림은 자동으로 나와요.

**궁합 테스트**: 놀이터의 "궁합 테스트"(`compat.html`)에서 두 캐릭터를 고르고 버튼을 누르면 랜덤 퍼센트와 문구가 나와요 (재미용). 퍼센트 구간별 문구는 `data/compat.js` 에서 고쳐요.

**능력 설명 접기**: 캐릭터 `info` 에 `"능력 부연설명": "긴 글"` (또는 `"능력 설명"`)을 쓰면 표의 능력 칸 아래 "설명 보기"로 접혀 있다가 눌러서 펼쳐져요. 줄바꿈은 `\n\n`.

**랜덤 파티 짜기**: 놀이터의 "랜덤 파티 짜기"(`party.html`). 포지션별 / 내가 고르기 / 전부 랜덤으로 4명을 정하고 게이트를 골라 공략해요. 캐릭터 `info` 의 `포지션` 과 `등급` 을 읽어서 성공 확률이 정해져요. 게이트 난이도와 결과 문구는 `data/party.js` 에서 고쳐요.

**길드**: 길드 소개는 `data/guilds.js` 에, 캐릭터의 소속은 `data/characters.js` 의 `guild` 칸에 써요. 비워두면 "소속 미정" 으로 나와요.

**세계관 글**: `data/world.js` 의 `sections` 를 고쳐요.

**만화 추가**: `images/comics/<만화id>/` 에 페이지 이미지를 올리고 `data/comics.js` 에 항목을 추가해요 (샘플 참고). `add.html` 위쪽에서 "만화" 를 고르면 페이지 파일을 한꺼번에 골라서 코드를 만들어줘요 (페이지 순서는 파일 이름의 숫자 순서). 만화는 갤러리에 그림과 같이 나와요 (위쪽 `전체 / 그림 / 만화` 로 나눠 볼 수 있어요).

## 테마

오른쪽 위 선택 칸으로 바꿔요. 다크 / 라이트 / 파스텔 / 헌터 / 백야 / 비바람 / 전갈. 고른 테마는 브라우저가 기억해요. (처음엔 다크)
새 테마는 `theme.js` 의 LIST 에 한 줄, `style.css` 맨 아래에 `:root[data-theme="이름"] {…}` 를 추가해요.

## 음악 (브금 / 플레이리스트)

`data/music.js` 에서 곡을 써요. 씹덕 / 클래식 / K POP / 배경음악 칸에 곡 7개씩 자리가 있어요.

- **유튜브 곡**: `{ title: "제목", artist: "가수", youtube: "영상ID" }` (영상 ID = 주소의 `v=` 뒤 글자)
- **mp3 파일**: `music/` 폴더에 올리고 `{ title: "제목", file: "music/파일.mp3" }`
- 오른쪽 아래 ♪ 버튼을 누르면 목록이 열려요. 페이지를 옮겨도 이어서 재생해요 (자동재생이 막히면 ▶ 를 한 번 눌러요).

## 글자 꾸미기

캐릭터 설명, 소개글, 세계관 글 어디서나 써요.

- `[무지개:S랭크]` `[금색:글자]` `[굵게:글자]` `[반짝:글자]`
- 색깔: `[빨강:글자]` `[파랑:...]` `[초록:...]` `[보라:...]` `[분홍:...]` `[노랑:...]` `[주황:...]` 또는 `[#ff00aa:글자]`
- `S랭크` `S급` `SS급` 같은 말은 그냥 써도 자동으로 무지개! (목록은 `data/site.js` 의 `rainbowWords`)
- 캐릭터 `info` 의 `등급` 칸에 `"S"` 만 써도 무지개

## 갤러리 검색 규칙 (단보루 스타일)

- `루티 바닐라` → 두 캐릭터가 같이 나온 그림
- `루티 -단체` → 루티가 나왔지만 "단체" 태그는 제외
- `작가:시은` → 시은이 그린 그림
- `공_유안` → 이름에 띄어쓰기가 있으면 `_` 로
- `현*` → "현"으로 시작하는 태그
- 같은 이름 캐릭터가 생기면 `이름(주인)` 으로 구분돼요. (예: `현랑(연우)`)

## GitHub Pages 켜기

1. 이 폴더 안의 파일 전부를 저장소에 올려요 (폴더째 드래그해도 돼요)
2. 저장소 `Settings → Pages → Branch: main / (root)` 선택 후 Save
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열려요

## 주의

- 파일 이름에 `%` `#` `?` 만 빼고 한글·띄어쓰기도 돼요. 그림이 "이미지를 찾을 수 없어요" 로 나오면 거기 적힌 경로와 GitHub 의 실제 파일 이름이 똑같은지(대소문자 포함) 확인해 보고, 그래도 안 되면 그 파일만 영어로 바꿔요
- `data/*.js` 를 고칠 때 쉼표(`,`)와 따옴표(`"`)를 빼먹지 않기! 사이트가 비어 보이면 거의 이 문제예요
- 웹 업로드는 파일당 25MB 까지예요. 큰 그림은 `thumb` 로 작은 미리보기를 같이 쓰면 빨라요
- 샘플 그림/만화(`sample`)는 지워도 돼요
